# swift-rfc-7233

> **Status: Namespace-reservation** — This package reserves the RFC 7233 namespace. RFC 7233 (HTTP/1.1 Range Requests) was obsoleted by RFC 9110; its range requests semantics are consolidated into HTTP Semantics/Caching and implemented in swift-rfc-9110. The package currently exposes only an empty `RFC_7233` namespace enum and is not independently implemented.
